# Agent development

- Work directly on `main` and push completed changes to `main`. This small agent project does not need feature branches or worktrees.
- Ask for clarification before planning code changes.
- Commit completed implementations, except changes awaiting the user's testing and confirmation.
- Never commit `.env`, credentials, or local `.avctl/` state.
- Keep README claims aligned with implemented and verified behavior. Distinguish local changes from deployment to Agentverse.
